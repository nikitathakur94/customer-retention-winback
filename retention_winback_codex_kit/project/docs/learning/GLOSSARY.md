# Glossary with project examples

RFM: recency, purchasing-day frequency and historical event-value proxy. Observation window: the 60 days before a fixed scoring cutoff. Label window: the following 28 days. Censoring: follow-up ends before the outcome is fully observable; latest labels stay null. Leakage: using information unavailable at scoring, such as later purchases or metadata. Calibration: predicted 80% non-repurchase should correspond to about 80% observed non-repurchase in comparable mature cases. Risk lift: top-K non-repurchase rate divided by the same cohort's prevalence. MDE: minimum detectable absolute rate difference under explicit power assumptions. ITT: intention-to-treat comparison using original assignment, including nonconverters. Uplift: estimated change caused by treatment, unlike risk or response probability. Qini: a ranking summary implemented with scikit-uplift, with held-out uncertainty rather than known individual causal labels.
